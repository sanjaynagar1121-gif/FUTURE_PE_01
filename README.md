# FUTURE_PE_01

## Task 1: AI Website Copy Generator for Local Businesses

### Objective
Create a complete AI-generated website copy set for a local business using structured prompts.

### Sample Business
**Bean & Bloom Café** — a fictional neighborhood café offering coffee, tea, breakfast, snacks, desserts, takeaway, and small-group seating.

### Tools Used
- ChatGPT
- GitHub
- Google Docs / MS Word (optional)

### Deliverables
1. Homepage copy
2. Services / offerings copy
3. CTA (Call To Action) copy
4. Structured prompts
5. Prompt logic and documented outputs

## Prompt Engineering Approach

The prompts follow a simple structure:

**Role → Business Context → Target Audience → Objective → Requirements → Tone → Output Format**

This structure keeps the generated copy focused, consistent, and ready to use on a website.

## Prompt Logic

### Homepage
The prompt asks the AI to create:
- A clear headline
- A value proposition
- A short introduction
- Key customer benefits
- A primary CTA

### Services / Offerings
The prompt asks the AI to:
- Identify the business offerings
- Give each offering a short customer-friendly description
- Focus on benefits rather than only listing features

### CTA
The prompt asks the AI to create:
- Contact-oriented calls to action
- Booking / visit / takeaway actions
- Short, action-oriented website text

## Final Output

The complete website copy is available in the `outputs/` folder.

## Note
The sample business used for this task is fictional and is intended to demonstrate the prompt-engineering workflow.
